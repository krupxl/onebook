## Current reading of the evidence

**C01, the Golden Rule.** No tradition's texts reject the rule. Under the project's rules, twelve traditions clearly teach that you should not harm others in ways you would not want to be harmed, and the thirteenth (Zoroastrianism) states it explicitly in its Tier 2 texts. Eleven meet the fuller form (do not *treat* others in any way you would not want). The candidate did not enter the Code for two reasons, and neither is a disagreement about values:

1. **Silence in founding texts.** The secular humanist declarations express the same concern through equal rights, dignity and "helping and not harming", but never state the test of using oneself as the measure. This is a gap in what the texts say, not an opposing teaching.
2. **The standing of texts within a tradition.** Zoroastrianism states the rule explicitly, but only in Pahlavi texts that one major branch accepts and another does not treat as binding. This is a question about how the project counts evidence, and it needs a decision from the project lead.

**What this means for the hypothesis so far.** One candidate is too few to judge. But the first result is consistent with the hypothesis: the only thing standing between the Golden Rule and the Code is evidence and procedure, not an irreducible clash of values. A pattern to watch in later candidates: traditions whose primary texts are short (secular humanism) or survive mainly as liturgy (the Avesta) may fail on silence rather than disagreement. If that recurs, the project may need a settled rule for silence, decided in advance, so that it is applied the same way every time.
