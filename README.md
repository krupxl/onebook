# The Common Code

The Common Code is a draft code of conduct, set out like a constitution. It is built only from rules of behaviour that thirteen of the world's traditions teach in their own texts.

The thirteen traditions, in a fixed order that is a convention and not a ranking, are: Hinduism, Judaism, Zoroastrianism, Buddhism, Jainism, Confucianism, Taoism, Stoicism, Christianity, Islam, Sikhism, the Bahá'í Faith and secular humanism.

## What it is

- **About conduct only.** Every article is about how to act, never about what to believe.
- **Built from the texts.** A principle is admitted only if every one of the thirteen traditions clearly teaches it in its own texts, with each citation checked.
- **A floor, not a ceiling.** Each article states the least that every tradition asks. Any tradition, community or person may ask more of themselves.
- **Offered, not imposed.** It belongs to no one. Anyone with evidence and good reason may challenge or improve it.

## What it is not

It is not a religion. It does not decide which tradition is right. It makes no claims about God, the soul, the afterlife or the nature of reality. It does not replace, rewrite or overrule any scripture.

## Where the traditions differ

Where the texts disagree on a question of conduct, the Code does not pick a side. The question goes into the **Register of Open Questions** (`register/`), where it is broken down into parts and studied through the texts, evidence and reasoning.

The project tests an honest hypothesis: that every disagreement on conduct can be narrowed until none is left. If that turns out to be false, the exact list of questions that cannot be narrowed is itself a useful result. Progress is tracked in `HYPOTHESIS.md`.

## How to read this repository

| File or folder | What it holds |
|---|---|
| `code/preamble.md` | The preamble to the Code |
| `code/articles/` | The admitted articles, one file each, with full evidence |
| `code/freedoms-of-conscience.md` | What the Code deliberately leaves to each person and tradition |
| `register/` | Open questions where the traditions' texts differ |
| `candidates.md` | Principles waiting to be tested, and their status |
| `METHOD.md` | How the work is done, so anyone can check it |
| `sources/corpus.md` | Which texts count as evidence for each tradition, and why |
| `sources/translations.md` | Which translations are used, and where translation changes meaning |
| `HYPOTHESIS.md` | Running tally of articles, open questions and what remains |
| `CHANGELOG.md` | History of every change |
| `CLAUDE.md` | The project brief that governs the work |

## How to challenge it

If you think a citation is wrong, a translation is unfair, a passage was missed, or an article asks more than a tradition really asks, open an issue with the reference and your reasoning. Every article records its evidence and its counter-evidence so that it can be checked.
