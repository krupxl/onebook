# Freedoms of Conscience

The Code is a floor, not a ceiling. This page lists what the Code deliberately leaves to each person and each tradition. Nothing here is an article. It is a record of what the Code does **not** decide.

## Left open by the nature of the Code

These follow from the project's settled decisions. They apply to every article.

1. **Belief.** The Code asks no one to believe anything about God, gods, the soul, what comes after death or the nature of reality.
2. **Which tradition is right.** The Code does not judge between traditions, and no article should be read as doing so.
3. **Worship and practice.** Prayer, ritual, food rules, dress, festivals, rest days and similar practices are left to each tradition and each person.
4. **Asking more.** Any tradition, community or person may ask more of themselves than an article asks. An article states the least that every tradition asks, never the most.
5. **Scripture.** The Code replaces, rewrites and overrules no scripture. Each tradition remains the interpreter of its own texts.
6. **Open questions.** Where the traditions' texts differ on a question of conduct, the Code takes no side. Those questions are recorded in the Register of Open Questions (`register/`).
